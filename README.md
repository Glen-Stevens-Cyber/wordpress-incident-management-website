# WordPress Cybersecurity Incident Management Website
## Project overview
This academic project involved researching incident management and incident response with no prior knowledge so we could then design and develop a five-page WordPress learning resource about cybersecurity incident management with the purpose of educating other cybersecurity students with similar levels of knowledge. This project was completed in my second academic year and during my BSc (Honours) Cyber Security studies at the Open University.
The original website was created inside of a university-managed WordPress environment so instead of a live website, the repository contains full page PDFs of the pages included on the website as well as the WordPress dashboard highlighting all of the pages created.
## Project case study:
To help the students gain a better understanding of how incident management and response would work in practice, a fictional case study was provided for the project below:
The website was based on a fictional small online retailer with 20 employees and approximately 10,000 customers.
Its network included:
•	A web server hosting the online shop
•	A networked file server
•	Employee computers
•	Network switches
•	A firewall-protected router
•	Encrypted personal information belonging to customers and employees
## Website and PDF contents
I produced five linked WordPress pages covering the following:
1.	Cybersecurity incident management – an introduction to incident management and the key incident-response processes.
2.	Cyber Security Incident Response Team – the formation of an appropriate CSIRT, the responsibilities of its members and why each member would be suited for that role.
3.	Cybersecurity incidents – Highlights 5 possible cyber security incidents the company in the case study should be aware of and why.
4.	Ransomware response playbook – a structured playbook based on how the organisation should react during a ransomware attack. Plan covers preparation, containment and analysis, eradication, recovery and reflection.
5.	Regulatory, legal and public response – This part of the incident response plan highlights the actions required to manage the wider consequences of a ransomware incident such as the responses required for regulatory, legal and public relations issues that could arise from a ransomware attack.
The pages were connected through a consistent navigation menu at the bottom of each page so that users could move easily through the learning resource.

## What I learned
This project not only introduced me to incident management and response but also provided me with my first practical experience with WordPress. 
While developing the website, I learned how to create and manage multiple WordPress pages, organise them through a clear navigation menu in the header and the bottom of each page, combine written and visual content, and present technical information in an accessible format that’s user friendly but also giving great detail on each page. 
When learning about incident management and response, I discovered how much detail must go into both processes in order to be able to react efficiently to all threats to minimise the repercussions and financial impact the organisation could face. Preparing my own fictional CSIRT, preparing for a ransomware attack and designing my own steps for the responses required made me realise why organisations need to be prepared and ensure everyone understands their roles. These steps helped me gain an understanding of how these processes can be applied to react to cyber security threats.
